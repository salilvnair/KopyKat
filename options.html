Sync map
0

One From (source) copies to many To (destinations). Only origins used here are ever touched — the map is the allow‑list. Wildcards like https://*.example.com work in either column.

Auto-reload mapped tabs on update

Reloads mapped tabs after the extension is reinstalled/updated so content scripts re-attach. Reloads discard unsaved page state.

Keyboard shortcut

Toggle the sync engine with Ctrl+Shift+Y (⌘+Shift+Y on Mac). Rebind at chrome://extensions/shortcuts.
